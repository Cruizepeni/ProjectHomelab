# PythoFetch

PythoFetch is a Python-based successor to [Neofetch](https://github.com/dylanaraps/neofetch), developed as part of ProjectHomelab.

It keeps the familiar system-information-and-ASCII-art style of Neofetch while providing a Python-native implementation designed for modern Windows, Linux, and future cross-platform ProjectHomelab use.

## Running PythoFetch

PythoFetch can be run in three main ways.

### Normal

Starts the ProjectHomelab PythoFetch terminal interface.

```text
PythoFetch
```

Packaged releases use:

```text
Windows: PythoFetch.exe
Linux:   ./PythoFetch.AppImage
```

### Classic

Displays PythoFetch in a traditional Neofetch-style layout.

```text
PythoFetch --classic
```

### Headless

Runs without the interactive terminal interface for scripting, automation, or structured output.

```text
PythoFetch --headless
```

Additional headless selectors and output formats are documented in the PythoFetch documentation.
